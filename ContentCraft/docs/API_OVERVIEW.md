# API overview
Base URL: `/api`. OpenAPI UI: `/docs`.
- `GET /health`
- `POST /auth/register`, `POST /auth/login`
- CRUD-lite `GET`, `POST`, `GET /{id}`: `/brands`, `/products`, `/audiences`, `/content-rules`, `/assets`, `/contents`, `/content-versions`, `/feedback`, `/analytics/events`
- `POST /ai/text`, `POST /ai/image`, `POST /image-analysis`
- `POST /publishing`, `GET /admin/status`
